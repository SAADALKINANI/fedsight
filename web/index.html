        About

        FedSight is a retrieval-augmented assistant for people who work with federal oversight and emergency-management data. It answers questions from three kinds of public sources:

        • GAO reports (87 reports from 2017 to 2020) on disaster response, public health, IT and cybersecurity, and program integrity.
        • FEMA: the current disaster-assistance regulations (44 CFR parts 201, 204 and 206), OpenFEMA dataset documentation, and the declarations and disaster-totals datasets.
        • CDC: overdose-prevention and preparedness web pages, plus provisional drug overdose death counts by state.

        What keeps it honest

        • It has to search before it answers, and it only answers from what the search returned.
        • Claude's citation feature ties each sentence to a passage or a row of query results. The server then checks every cited quote against the source text and every number against the evidence.
        • If it can't support an answer, it says so instead of guessing.
        • Personal information in questions is redacted before it reaches the model or the logs, obvious prompt-injection attempts are refused, and text inside documents is treated as data, never as instructions.
        • Data questions run as read-only SQL against an allow-listed set of tables.

        GAO reports come from a public research dataset and stop at mid-2020, so questions about newer GAO work won't find an answer. FEMA and CDC sources are current. Not legal, medical or financial advice. Source documents are public U.S. government works. Built by Saad Alkinani.
